   OpenShift Route: {{ if .Values.route.host }}https://{{ .Values.route.host }}/{{ else }}oc get route {{ include "cert-alert.fullname" . }} -n {{ .Release.Namespace }}{{ end }}
{{- else if .Values.ingress.enabled }}

   (the first start runs the database migrations).

2. License
   The license screen is /admin/license (Administration -> License). Sign in as one of
   security.adminIdentifiers{{ if not .Values.security.adminIdentifiers }} - NONE ARE SET: set security.adminIdentifiers, or nobody can
   reach it{{ end }}. Until a license is installed only sign-in and that screen work.
{{- range .Values.security.adminIdentifiers }}
{{- if and (contains "@" (toString .)) (not (contains "=" (toString .))) }}
   WARNING: security.adminIdentifiers lists {{ . }}, an e-mail address. It is ignored and
   grants nothing: list that administrator's uid, or the DN of their entry, instead.
{{- end }}
{{- end }}
{{- if include "cert-alert.licenseSupplied" . }}
   The license you supplied was copied into the license volume, unless one was already
   installed there (a later upload on the license screen is never overwritten).
{{- else }}
   No license was supplied: upload it on the license screen, or set license.existingSecret
   or --set-file license.file=./license.lic on the next helm upgrade.
{{- end }}
   An evaluation license comes from the ENS licensing portal (product "certalert").
   The license screen shows this installation's id; enter it on the portal to bind a
   license to this installation. Once the license has been checked (after the first
   sign-in), the id is also in the license volume:
     kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "cert-alert.fullname" . }} -- cat /var/lib/ens/certalert/installation-id

3. Keep the license volume
{{- if .Values.persistence.license.enabled }}
   PVC {{ include "cert-alert.licenseClaimName" . }} holds the license, the installation id and
   the license revisions seen. helm upgrade keeps it.{{ if not .Values.persistence.license.existingClaim }} helm uninstall DELETES it, and the
   installation then gets a new id: a bound license must be re-bound on the portal. To keep
   it across a reinstall, create the PVC yourself and pass persistence.license.existingClaim.{{ end }}
{{- else }}
   WARNING: persistence.license.enabled=false - the license and installation id are lost
   with every pod restart. Evaluation only.
{{- end }}
{{- if not (or .Values.webhooks.existingSecret (include "cert-alert.webhooks.secretKey" .)) }}

Webhooks: no secret key, so their signing secrets and URLs are stored unencrypted. Set
webhooks.secretKey (openssl rand -base64 32) or webhooks.existingSecret; what is stored is
encrypted at the next start.
{{- end }}

next upgrade){{ end }}; a failed dump stops the upgrade. See the chart README, "Backups and upgrades".
